This is a python wrapper for controlling the EPSON TM-T20 receipt printer.
It has default Text formating, bitmap image printing, qr and barcode generation.

Its recomended to download the EPSON TM-T20 Utility and set the printer up before using the wrapper.

If the printer is setup in USB Vendor class: use TMUSB in the usb_port parameter
If the printer is setup in USB Printer class: use USBPRN in the usb_port parameter
